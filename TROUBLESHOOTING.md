# Troubleshooting

Common issues with **Hide Items (Custom)** and how to resolve them.

## Nothing is hidden after picking a pattern

Check the glob that was written:

1. Command Palette > **Preferences: Open Workspace Settings (JSON)**
2. Look at the `files.exclude` block.

Patterns must use forward slashes (`/`) on **every** platform, Windows
included. A pattern such as `src\components\*.ts` can never match, because in a
glob `\` is an escape character rather than a path separator.

This was fixed in **v1.0.4**. If you upgraded from an earlier version and see
backslashes in `files.exclude`, those entries were generated by the old code:
remove them and hide the items again.

## Hidden items come back when I reopen the folder

Excludes are always written to **workspace** settings
(`.vscode/settings.json`). They are lost if:

- the folder is opened as a different workspace,
- `.vscode/settings.json` is not committed and you cloned fresh, or
- another tool rewrites that file.

There is no global/user-level mode; hiding is per workspace by design.

## More is hidden than I expected

A bare file name such as `Button.test.ts` matches that name in **any** folder.
Pick a path-qualified option from the picker (for example
`src/components/Button.test.ts`) when you only want one specific file hidden.

To skip the picker entirely and always hide the exact item you clicked, set:

```json
"explorerExclude.showPicker": false
```

## I hid something and cannot get it back

Use the Hidden Items pane in the Explorer:

- **Toggle Visibility** temporarily reveals everything while keeping your list.
- **Enable All** / **Disable All** turn every rule on or off.
- **Reset Hidden Items** clears the list completely.

## The eye icon does not restore my rules

**Toggle Visibility** snapshots `files.exclude` into `explorerExclude.backup`
and restores it when toggled again. If that setting is non-empty, the toggle is
still active, so click it once more. Do not edit `explorerExclude.backup` by
hand.

## Hidden files still appear in Search and Quick Open

`files.exclude` only affects the Explorer tree. To hide the same items from
search, add matching patterns to `search.exclude` in your settings.

## The Hidden Items pane is missing

It is contributed to the Explorer view. If it is not visible, right-click the
Explorer title bar and make sure **Hidden Items** is checked. Also confirm the
extension is enabled for the current workspace or profile.

## Reporting a problem

Please include:

- VS Code version (**Help > About**)
- Extension version
- The contents of `files.exclude`
- The exact path you tried to hide

Issues: https://github.com/purduepete/hide-items-custom-vscode-extension/issues
